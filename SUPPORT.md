# Support

UAWP is currently maintained on a best-effort basis.

- Usage questions and reproducible defects: open an issue at
  <https://github.com/vibemaker-community/uawp/issues>.
- Feature proposals: start with the feature-request issue form.
- Security or conduct concerns: use the private process in [SECURITY.md](SECURITY.md).

Before reporting a defect, run `uawp status --format json` when safe and remove
workspace content, tokens, usernames, absolute private paths, and other
sensitive information. UAWP does not require a copy of your private project or
Agent conversation to diagnose most problems.

Commercial support, service-level agreements, and proprietary licensing are
not included in the public project and may be offered separately in the future.
