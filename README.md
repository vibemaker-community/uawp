# UAWP — Universal Agent Workspace Protocol

UAWP is a planned, agent-neutral protocol and toolchain for safely resuming,
owning, synchronizing, checkpointing, and handing off work across agent
sessions in a shared project workspace.

The product is currently at the architecture approval gate. No product code
has been created yet.

Review the [Product Engineering Kickoff and Handoff Specification](docs/superpowers/specs/2026-09-21-uawp-product-engineering-design.md)
before implementation planning begins.
